# QuickPOS Landing Page

A professional, responsive, and pixel-perfect landing page for QuickPOS built with PHP, HTML5, and CSS3. 
This project demonstrates modern UI/UX design and professional workflow practices using Jira, GitHub, and Slack.

## Features
- **Modern UI/UX**: Includes a glassmorphic hero mockup, smooth scroll, and CSS hover transitions.
- **Responsive Layout**: Designed for desktops, tablets, and mobile devices natively.
- **PHP Contact Form**: Form submission with server-side validation for blank fields and email format correctness.
- **All Core Sections**: 
  1. Navigation & Header
  2. Hero Section
  3. Features
  4. Pricing Setup
  5. Contact Us Form
  6. Footer

## Setup Instructions

1. **Prerequisites**: Download and install a local server environment such as **XAMPP** or **MAMP** to process the PHP form script.
2. **Installation**: 
   - Extract the project folder.
   - Move the `quickpos-landing-page` folder into your server's root directory:
     - For XAMPP: Place inside `C:\xampp\htdocs\`
     - For MAMP: Place inside `Applications/MAMP/htdocs/`
3. **Execution**:
   - Start Apache from your XAMPP/MAMP control panel.
   - Open your web browser and navigate to: `http://localhost/quickpos-landing-page/`
4. **Testing Contact Form**:
   - Scroll down to the Contact section, fill out the Name, Email, and Message.
   - Hit "Send Message". You will see it validate and redirect to the `thank-you.html` page successfully.
